## ✅ Өзіңді тексер: 7 сұрақ

Әр сұрақтың бір ғана дұрыс жауабы бар. Алдымен өзіңіз шешіп, сосын «Жауабы» жазуын басыңыз.

**1. Google Colab деген не?**

- А) Python кодын браузерде тегін іске қосатын орта
- Ә) Python-ды компьютерге орнатып, баптайтын арнайы бағдарлама
- Б) Нейрондық желілерді оқытатын кітапхана
- В) Деректер сақталатын бұлттық дискі

<details><summary>Жауабы</summary>

**А)** Python кодын браузерде тегін іске қосатын орта. Colab-та код Google-дың серверлерінде орындалады, сондықтан компьютерге ештеңе орнатудың қажеті жоқ. Онда видеокартаны (GPU) да тегін қосуға болады.

</details>

**2. Python кодында # белгісінен кейінгі мәтін не істейді?**

- А) Келесі жолдағы кодты қателерге тексереді
- Ә) Түсініктеме: Python оны орындамайды
- Б) Жаңа айнымалыны жариялап, оған мән береді
- В) Мәтінді экранға басып шығарады

<details><summary>Жауабы</summary>

**Ә)** Түсініктеме: Python оны орындамайды. Түсініктемелер адамдарға арналған: олар кодтың не істейтінін түсіндіреді, ал Python оларды орындамайды.

</details>

**3. bagalar = {"Айгерім": 5, "Нұрлан": 4} сөздігінде "Айгерім" деген не?**

- А) Мән
- Ә) Индекс
- Б) Кілт
- В) Функция

<details><summary>Жауабы</summary>

**Б)** Кілт. Сөздік «кілт — мән» жұптарын сақтайды. bagalar["Айгерім"] өрнегі 5-ті береді.

</details>

**4. for i in range(3): print(i) коды не шығарады?**

- А) 3
- Ә) 0 1 2 3
- Б) 1 2 3
- В) 0 1 2

<details><summary>Жауабы</summary>

**В)** 0 1 2. range(3) нөлден басталып, 3-ке жетпей тоқтайды: 0, 1, 2. Python-да санау әдетте нөлден басталады.

</details>

**5. NumPy кітапханасының ЖИ үшін басты пайдасы неде?**

- А) Ол сандар массивтерімен циклсіз, жылдам есептейді
- Ә) Ол деректерден әдемі графиктер мен диаграммалар салады
- Б) Ол кестелерді Excel файлына сақтап, ашуға көмектеседі
- В) Ол интернеттен дайын деректер жиындарын жүктейді

<details><summary>Жауабы</summary>

**А)** Ол сандар массивтерімен циклсіз, жылдам есептейді. np.array([1, 2, 3]) * 2 бір амалмен [2, 4, 6] береді. Нейрондық желілердің барлық есептеуі осындай массив амалдарына сүйенеді.

</details>

**6. Кездейсоқ сандар генераторына тұқым (seed) беру не үшін керек?**

- А) Бағдарламаның жұмысын жылдамдату үшін
- Ә) Сандарды бұрынғыдан да кездейсоқ ету үшін
- Б) Кодтағы қателерді автоматты түрде табу үшін
- В) Нәтижелерді дәл қайталап алу үшін

<details><summary>Жауабы</summary>

**В)** Нәтижелерді дәл қайталап алу үшін. Тұқымды белгілеу тәжірибені дәл қайталауға мүмкіндік береді. Кітаптағы нәтижелерді қайталау үшін біз тұқымды жиі көрсетеміз.

</details>

**7. Кестелермен (DataFrame) жұмыс істеуге арналған кітапхана қайсы?**

- А) Matplotlib
- Ә) random
- Б) pandas
- В) NumPy

<details><summary>Жауабы</summary>

**Б)** pandas. pandas кестелерді оқиды, сүзеді, топтайды және статистикасын есептейді. Matplotlib — графиктерге, NumPy — массивтерге арналған.

</details>
