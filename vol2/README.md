# «Машина қалай үйренеді? 2-том» — блокноттар

«Машина қалай үйренеді? 2-том. Генеративті жасанды интеллект: PyTorch, генеративті модельдер,
үлкен тілдік модельдер және RAG» кітабының әр тарауына арналған Google Colab блокноттары.

## Қалай қолдану керек?

1. Кітаптағы тараудың бірінші бетіндегі QR кодты смартфонмен сканерлеңіз немесе төмендегі кестеден «Open in Colab» белгісін басыңыз.
2. Өз көшірмеңізді сақтау үшін құралдар тақтасындағы **Copy to Drive** (орысша интерфейсте — **Копировать на Диск**) батырмасын басыңыз.
3. GPU керек болса: **Runtime → Change runtime type** (орысша — **Среда выполнения → Сменить среду выполнения**) бөлімінде GPU-ды таңдаңыз. Кітаптағы модельдердің бәрі процессорда да оқытылады.
4. Ұяшықтарды жоғарыдан төмен қарай ретімен іске қосыңыз (**Shift + Enter**).

Тарауларға керек деректер мен модель осы репозиторийден автоматты түрде жүктеледі.
«Міндетті емес» деп белгіленген ұяшықтар қосымша бағдарламаны (мысалы, тілдік модельдерді
өз компьютерде іске қосатын [Ollama](https://ollama.com/)) немесе өз файлыңызды қажет етеді: олар әдепкіде орындалмайды.
