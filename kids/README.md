# «Машина қалай үйренеді? Жас зерттеушіге» — кесте файлдары

5–7-сынып оқушыларына арналған кітаптың электрондық кестелері. Файлдарды Microsoft Excel, Google Sheets немесе LibreOffice Calc бағдарламасында ашуға болады.

| Файл | Тарау | Мазмұны |
|---|---|---|
| `k05_tree.xlsx` | 5 | Шешім ағашы `IF` формуласымен |
| `k07_trend.xlsx` | 7 | Бой мен аяқ киім өлшемі, `FORECAST` арқылы болжам |
| `k09_neuron.xlsx` | 9 | Жасанды нейрон: салмақтар, қосынды және шекті мән |
| `k10_learning.xlsx` | 10 | Нейронды оқыту: 40 қадам, салмақтарды түзету |
| `k14_sentiment.xlsx` | 14 | Пікір анықтағыш: сөздердің ұпайы және жаңа пікірлер |

Excel-дің орысша нұсқасында функциялар басқаша аталады: `IF` → `ЕСЛИ`, `SUMPRODUCT` → `СУММПРОИЗВ`, `COUNTIFS` → `СЧЁТЕСЛИМН`, `SEARCH` → `ПОИСК`, `ISNUMBER` → `ЕЧИСЛО`, `FORECAST` → `ПРЕДСКАЗ`. Файлды ашқанда бағдарлама оларды өзі аударады.
