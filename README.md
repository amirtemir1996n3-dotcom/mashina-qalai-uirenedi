# «Машина қалай үйренеді?» — кітаптың блокноттары мен деректері

[![Блокноттарды тексеру](https://github.com/amirtemir1996n3-dotcom/mashina-qalai-uirenedi/actions/workflows/notebooks.yml/badge.svg)](https://github.com/amirtemir1996n3-dotcom/mashina-qalai-uirenedi/actions/workflows/notebooks.yml)

Бұл репозиторийде «Машина қалай үйренеді? Машиналық оқыту мен нейрондық желілер: оқушыларға арналған практикалық кітап» кітабының
әр тарауына арналған Google Colab блокноттары және жобалардың деректер жиындары сақталған.

## Қалай қолдану керек?

1. Кітаптағы тараудың бірінші бетіндегі QR кодты смартфонмен сканерлеңіз немесе төмендегі кестеден «Open in Colab» белгісін басыңыз.
2. Блокнот Google Colab-та ашылады. Өз көшірмеңізді сақтау үшін құралдар тақтасындағы **Copy to Drive** (орысша интерфейсте — **Копировать на Диск**) батырмасын басыңыз.
3. Ұяшықтарды жоғарыдан төмен қарай ретімен іске қосыңыз (**Shift + Enter**).

Блокноттарда тек код пен бөлімдердің атаулары берілген. Әр қадамның түсіндірмесін кітаптан оқыңыз.

## Деректер (`data/`)

| Файл | Сипаттама |
|---|---|
| `news_kz.csv` | 300 қазақша жаңалық тақырыбы, 5 санат (24-тарау). Тақырыптар кітап үшін нақты жаңалықтардың стилінде арнайы жазылған. |
| `astana_temp.csv` | Астананың тәуліктік орташа температурасы, 2015–2024 (25-тарау). **Модельденген деректер:** көпжылдық айлық орташалар нақты бақылаулардан алынған, күнделікті ауытқулар кездейсоқ модельмен жасалған. |
| `wheat_kz.csv` | 3 облыстағы 90 алқаптың 10 жылдық бидай өнімі (26-тарау). **Модельденген деректер**, нақты шаруашылықтардың өлшемдері емес. |
| `xor_network.xlsx` | XOR есебін шешетін нейрондық желі электрондық кестеде (10-тарау). |
| `kitap.txt`, `qa.txt`, `tom1.json`, `mektep.json` | 2-томның деректері: 1-томның мәтіні, сұрақ-жауап жұптары және ойдан шығарылған мектептің құжаттары. Толығырақ — [`vol2/README.md`](vol2/README.md). |

Нақты ауа райы деректерін [Open-Meteo](https://open-meteo.com/) сервисінен, ал облыстар бойынша егін статистикасын
Қазақстанның Ұлттық статистика бюросынан ([stat.gov.kz](https://stat.gov.kz)) алуға болады.

## Тараулардың серік беттері: бейнесабақ және тест

Кітаптың әр тарауының соңындағы «Өзіңді тексер» блогында QR код бар. Ол [`tom1/`](tom1/README.md) бумасындағы
серік бетке апарады: онда 2 минуттық бейнесабақтың сценарийі және жауаптары бар өзін-өзі тексеру тесті (6–7 сұрақ) берілген.

## Сериядағы басқа кітаптар

- **2-том. Генеративті жасанды интеллект** — PyTorch, автокодировщиктер, GAN, диффузия, GPT-ті нөлден құрастыру, үлкен тілдік модельдер, RAG және агенттер: 20 тараудың блокноттары [`vol2/`](vol2/README.md) бумасында.
- **Жас зерттеушіге (5–7-сыныптар)** — кодсыз жеңіл нұсқа: Teachable Machine және электрондық кестелер, файлдары [`kids/`](kids/README.md) бумасында.

## Қате таптыңыз ба?

Кітаптағы немесе блокноттағы қатені [мына форма арқылы](https://github.com/amirtemir1996n3-dotcom/mashina-qalai-uirenedi/issues/new?template=errata.yml)
хабарлаңыз. Расталған қателер мен түзетулер [ERRATA.md](ERRATA.md) бетінде жарияланады.
Барлық кітаптың қазіргі басылымы — **1-басылым, 2026**.

## Автоматты тексеру

Барлық блокнот айына бір рет [GitHub Actions](https://github.com/amirtemir1996n3-dotcom/mashina-qalai-uirenedi/actions/workflows/notebooks.yml)
арқылы кітапханалардың соңғы нұсқаларымен іске қосылады (`tools/run_notebooks.py`).
Бір блокнот бұзылса, «Issues» бөлімінде автоматты хабарлама ашылады. Файл жүктеуді немесе
пернетақтадан енгізуді күтетін ұяшықтар `optional` белгісімен белгіленген және тексеруде өткізіледі.
Тексеруді өз компьютеріңізде де іске қосуға болады:

```bash
pip install -r tools/requirements-vol2.txt
python tools/run_notebooks.py vol2
```

## Талаптар

Блокноттар Google Colab ортасына арналған: онда барлық кітапхана (NumPy, pandas, scikit-learn, matplotlib, TensorFlow/Keras) алдын ала орнатылған.
Өз компьютеріңізде іске қосу үшін Python 3.10+ және осы кітапханалар қажет.
